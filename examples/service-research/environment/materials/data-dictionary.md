# 数据说明

本文件及 CSV 是人为构造的协议验证材料，不是真实校园数据。数据时间范围为 2026 年 6～8 月，每月每站点一条记录。

| 字段 | 定义 / 单位 |
| --- | --- |
| `month` | 统计月份 |
| `site` | 服务站点：北站、南站 |
| `available_slots` | 当月开放预约的服务名额，单位：个 |
| `booked_slots` | 当月被预约的服务名额，单位：个 |
| `completed_visits` | 当月实际完成的服务，单位：次 |

一个名额最多对应一次预约和一次完成服务。没有跨月结转；未完成预约不计入实际完成次数。人数与次数不同，本材料不能推导独立用户人数。

预约率 = 已预约名额 / 可预约名额；履约率 = 实际完成次数 / 已预约名额。季度比率用季度汇总分子除以季度汇总分母。空余名额不等于闲置成本，材料未提供工时、成本或用户满意度。
