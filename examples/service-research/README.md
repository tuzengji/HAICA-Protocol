# HAICA Protocol 多产物任务示例

本目录符合 [HAICA Protocol V1.5](../../HAICA-Protocol.md)，使用人为构造的数据，演示报告、指标表和图片的交付与两层评分。

## 文件

- `instruction.md`：公开题面。
- `task.toml`：任务与交付要求。
- `environment/materials/`：公开数据与口径说明。
- `tests/evaluation.toml`：私有评分计划。
- `tests/references/`：私有事实基准与口径。

考生只接收题面、environment 和平台生成的交付要求。

## 自动评分

结束评测后，后台脚本选择最后一次成功提交，按顶层 rubric 自动判分。每条顶层只评一个产物，全部子项共用一次 LLM 请求或一个 Agent 会话；返回逐项档位、理由和证据，程序算分。

| 顶层 rubric | 方向 | 子项数 | 唯一待评产物 | 判卷方式 | 最高加/扣分 |
| --- | --- | ---: | --- | --- | ---: |
| 指标计算准确 | 加分 | 5 | 指标表 metrics | LLM | 40 |
| 分析与建议有据可依 | 加分 | 3 | 报告 report | LLM | 30 |
| 来源与统计口径清楚 | 加分 | 4 | 报告 report | LLM | 15 |
| 图表内容准确且标注完整 | 加分 | 3 | 图表集 charts | Agent | 15 |
| 图表阅读障碍 | 减分 | 1 | 图表集 charts | Agent | 20 |

正常完整提交需要 **3 次直接 LLM 请求和 2 个 Agent 会话**，不含失败重试。图表例采用 Agent 演示逐张读取证据；若平台能在一次请求中完整提供全部图像，也可明确配置为直接 LLM。私有事实基准、数据字典不是待评产物。

本修订 `example-1.5-001` 沿用 `weighted_sum/v1`，基础分为 0。四个加分项满分合计 100；阅读障碍项最多扣 20。组内子项等权，最终结果范围 -20～100，仅最后按 half-up 保留两位小数。省略 `direction` 等同于 `add`；不要求其他任务增设扣分项。

`report` 接收一份 Markdown/PDF/DOCX（最多 10 MiB）；`metrics` 接收一份 CSV（最多 1 MiB）；`charts` 是一个文件集产物，接收 1～3 张 PNG/JPEG（每张最多 2 MiB，合计 6 MiB）。读取上限见 task.toml。

文件格式和哈希由程序校验；模型保留全部 16 个子项的判断。缺交或无效输入按前置规则把依赖项原始分与贡献设为 0，不伪造模型调用；评分服务故障保留空总分。

## 验证与使用

使用支持 V1.5 的框架核验版本、单产物绑定、两层结构、能力、方向、加分合计和容量。结构校验不调用模型，不证明判分质量；模型验证需另外保存真实请求或会话，以及正确、部分正确、错误和缺交样例结果。

此通用示例为适应单产物边界，把报告、图表分别与固定事实基准核对，不再在同条 rubric 中交叉读取其他交付槽位。它不是任何真实任务的自动等价迁移范例；真实题若含跨产物要求，须另外验证拆分后的评分含义。

历史题包继续按所属版本运行，原包和成绩不变。此示例不代表真实业务。
